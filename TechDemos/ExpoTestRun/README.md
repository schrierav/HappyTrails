# Tech Demo-- Run this on your phone!

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).
For our purposes, this should be seen as a demo of how we'll run our development environment.

## Get started
1. Get your phone ready

Install Expo Go from your app-store of choice. Make an account. For local development, we shouldn't even need to be part of the same org AFAIK.

2. Install dependencies

   ```bash
   npm install
   ```

3. Start the app

   ```bash
   npx expo start
   ```

You should see a big QR code appear. Scan it with your phone. You're in!
